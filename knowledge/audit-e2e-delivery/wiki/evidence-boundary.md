# 证据边界

本页整理本主题材料中关于“材料能证明什么、不能证明什么”以及来源登记要求的知识事实。PDF 知识沿用 r2（当前来源）；引用定位可在 [delivery-r1.md](../readable/delivery-r1.md) 与 [evidence-r2.md](../readable/evidence-r2.md) 逐条核对。

## 材料用途边界

- 本批材料仅用作**文件整理／知识整理验收**，输入版本分别为 **audit-wiki-r1**（[delivery-r1.docx](../raw/delivery-r1.docx) 段落 1）与 **audit-wiki-r2**（[evidence-r2.pdf](../raw/evidence-r2.pdf) 第 5 页）。
- 材料**不代表业务效果通过**。
  来源：[delivery-r1.docx](../raw/delivery-r1.docx)（DOCX 段落 1）。
- 知识生效日期未知。
  来源：[delivery-r1.docx](../raw/delivery-r1.docx)（DOCX 段落 3）；[evidence-r2.pdf](../raw/evidence-r2.pdf)（PDF 第 5 页）。

## 判定边界

- **文档保存、静态检查或 HTTP 200 不代表业务成功。**
  来源：[evidence-r2.pdf](../raw/evidence-r2.pdf)（PDF 第 3 页，读取正文已核对完整）。
- **算力变体的业务等效及成本收益需双侧 Run 比较。**
  来源：[evidence-r2.pdf](../raw/evidence-r2.pdf)（PDF 第 4 页，读取正文已核对完整）。

即：格式与接口层面的“看起来成功”不能替代业务效果判定；算力变体的等效性与成本收益结论须有 Run 级比较证据。材料未给出具体的比较方法、阈值或验收口径，此处不作推断。r1 的对应观察记录保留于 [readable/evidence-r1.md](../readable/evidence-r1.md)（读取正文与原件内容流存在差异，原因尚未确认，当前改用 r2）。

## 来源登记要求

- 资料原件保存**来源与 SHA-256**。
  来源：[evidence-r2.pdf](../raw/evidence-r2.pdf)（PDF 第 1 页）。
- 知识正文保留 **PDF 页码**和 **DOCX 段落**定位。
  来源：[evidence-r2.pdf](../raw/evidence-r2.pdf)（PDF 第 2 页）。

本主题的来源登记按上述要求单处维护于 [index.md](../index.md)。
