# 标签证据与反例

标签证据至少说明规则/复核者/判定器版本和引用。多任务不能使用未公开的编号顺序仲裁；缺主语和对象不能猜域；source 字段不等于模型看过的事实。

后验完整轨迹可以帮助判定已执行动作是否合理，但不能比较从未执行的替代分支。未执行分支先标 unknown，必要时在可恢复环境验证。执行报错未必说明工具选错；业务 PARTIAL 也未必说明智能体失败。

可直接程序核对的样例：候选是否可用、任务版本来自本轮目录、查询 runId 来自发起回执、相同 requestId 是否复用、数值和 URL 是否忠于服务结果。自然语言表达是否清晰、语义路由泛化和未执行动作优劣需要额外判断。

目标概率含义写清：教师投票、动作成功率、偏好权重和模型校准概率分别管理。标准 Kev hard-label 评估不等于可接受集合评分。若任务应允许多个答案，先建立适用的评价和目标合同。
