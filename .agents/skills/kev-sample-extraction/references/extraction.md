# 状态抽取检查

读 core data-contract.md。检查每个状态事实和候选从哪条可见事件来，事件 seq 必须早于决策边界。静态规则来自明确版本的合同。

把当前模型选择整体从输入移除；以前步骤的合法动作与结果可以保留。辅助 token usage、stream、review、label 和最终回执不能混入早先输入。

反事实检查：改变未来终态、最终答案、未来工具目录，不影响此前 state/question；改变之前的工具目录则应改变候选；改变早先 runId 应只更新相应 binding，不应生成新的执行事实。

inspection-v1 的 reference 合同仅用于示范有界状态投影。它不保证所有巡检表达的最佳动作，也不自动生成 verified 标签。对超过预算的样本，保留原始证据并改进状态构造，不盲截断。
