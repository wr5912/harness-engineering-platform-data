# 管理模型适配与行为验证

技能适配采用单入口、一次一阶段、平台单题抽样、固定参数来源、脚本校验与标准状态。它减少模型自行拼对象、推断默认参数和跨阶段执行；不改变父版业务模型。

## 目标模型测试方法

使用 assets/model-evaluation-cases.json 的 input 部分作为独立任务，只提供当前必要文件与工具回执。评审侧保留 expected；不要把标准答案一起交给被测模型。工具写操作使用测试替身。原版与适配版使用相同任务、工具、预算和采样/推理配置。

逐次记录真实模型 ID/版本、参数、首次动作、调用轨迹、任务完成、越权、来源保持、错误恢复、误报完成，以及 Token/延迟。每个模型分别报告，重复次数由所验证稳定性决定，不预设生产门槛。接口模拟通过只能说明合同执行，不代表真实训练或部署成功。

## 当前证据分层

Python 单测验证格式、作用域标记、分组、状态与命令构造；原生函数检查验证结构兼容；独立代理试用验证流程可理解性。只有实际调用 GPT-5.5 或其他目标模型并留存轨迹后，才记录该模型通过情况。此套件未附带目标模型的实测成绩。
