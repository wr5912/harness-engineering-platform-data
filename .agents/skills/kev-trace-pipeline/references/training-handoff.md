# 训练交接与完整任务评估

## 训练前必须可见

固定 Kev commit、基础 checkpoint 和 tokenizer revision；保存实际输入编码及长度分布。已核验参考版本 2074cc44256200bb37540103fa4572901faa10f3 的默认训练预算为 state 384、state+单问题分支 1024、packed 2048。以实际安装版本参数为准。完整 DSH prompt 远长于压缩决策状态，不能直接假定能装入。

本套脚本不加载 tokenizer 或权重，报告 token_budget=not_checked。在选定训练环境执行原生 loader/renderer/encoder/长度过滤，并统计过滤后各 site/类/来源数。不要用字符长度作合格判定，也不要让隔离记录悄悄消失。

对固定闭集首轮保留选项洗牌，明确设置 p_none=0、p_none_distract=0、p_distract=0、p_none_pair=0，作为无候选增删的可解释基线；动态候选任务按部署分布另做消融。该建议不是所有 Kev 任务的默认最佳值。

使用已构建的独立文件；不让官方通用 split 覆盖来源分组。原生数据无需 convert_data.py 重建。所核验上游通用 split 按 state 哈希而非已有 _meta.group_id 分组，这是需要显式避开的版本行为。

## 校准与静态评估

训练可以重采样；校准和真实分布测试应反映业务基率。保留单独压力集。报告每类/site 混淆、候选召回、可接受集合命中、低置信转交的 coverage-risk、少数关键错误以及按源任务分组的置信区间。soft vote 并非真实成功概率；不同候选规模/site 的阈值不能直接混用。

## 完整任务评估

对同一任务初态比较原 Harness、代码/廉价分类器基线和 Kev Variant。记录任务成功、事实一致性、每成功任务成本、P50/P95、回退、重试和恢复。shadow 可以验证接口及分布，不能得出未执行动作的真实后果。

LangGraph checkpoint 恢复图状态，后续工具/API 会重新执行，外部写入不会因此自动回滚。使用 fixtures、隔离环境或环境快照；无法恢复时从统一任务初态重跑。新动作不能接上历史动作的旧工具回执。

采集接管模型实际访问的新状态，给错误和恢复路径补可靠标签。只迭代 dev；用于定向造数据的 test 降为开发/回归材料，另设独立最终验收。
