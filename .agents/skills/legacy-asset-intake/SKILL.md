# 旧资产只读清点

将来源视为待检查材料，使用 `platform_agents legacy/inspect {path}`。path 必须是当前数据根 `evolution/history/imports/` 内的实际相对路径，例如 `evolution/history/imports/<已存在来源>`；不能把任意主机路径、程序根或凭据目录作为来源。接口不自动下载、复制或导入缺失文件，未提供可访问来源时说明需先准备的对象。

检查结果分开说明实际观察、业务语义待确认项、迁移缺口和建议目标映射。根据清单选择必要内容；目录相似不代表不同 Runtime 行为等价。后续业务迁移通过 `harness-guided-workflow` 和独立 Experiment 办理，需要平台实际支持的读取、装配及验证能力；本检查动作本身不授权导入或激活。

- 不解压归档，不执行脚本、Hook、Plugin、Skill、Workflow 或配置，不安装其中依赖，不加载凭据。
- 敏感内容不回显，只保留检查器给出的风险类别和必要定位。检查通过只表示覆盖的结构检查未发现问题，不证明业务正确或可运行。
- 使用原始检查结果区分未发现项、`review_required` 和读取错误；告警不能解释为机器通过。
- 检查器限制归档大小、展开大小、成员数及路径；支持格式与实际回执一致。遇到不支持的压缩方式保留原摘要并说明缺口，不放宽检查或自行执行格式转换。

迁移后使用目标 DSH 的新 Session 和真实 Run 验证行为。记录来源与选择理由，不复制整个 Runtime HOME 或用原归档作为现行资产的第二份维护副本。
