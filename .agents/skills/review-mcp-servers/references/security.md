# MCP 安全审查

先确定受审方是服务器、宿主、网关还是组合，以及它能访问的目标、身份、网络和数据。只把受该方控制且处于审查范围的缺陷归给该方。以下规范条款以 `2026-07-28` 为例，审查其他版本时核对对应原文。

平台适用范围以 [入口约定](../SKILL.md#平台入口与边界) 为准。下表的身份隔离、审批、缓存信任及限流检查仅在目标版本和实际承诺适用时开展，不据此新增平台门禁、调用方 SOP 或模型调用额度。匿名共享模式不存在承诺的访客隔离时，S01 的双身份场景不适用；第三方服务的整改归其维护方。

「协议」按所引条款的 MUST 或 SHOULD 判定。「实践」依据公开安全指南。「团队」用于项目明定的发布约束。采集请求、响应、执行器调用和前后状态时，用测试身份、合成对象及哨兵字符串替代真实凭据和敏感数据。

| 编号与适用条件 | 最小证据与复验 | 失败判据及依据 |
|---|---|---|
| S01 · 有身份或对象访问边界 | 用身份 A 访问获准对象，再用无权的身份 B 直接请求同一工具、资源 URI 或作业句柄。核对授权分支、下游动作和返回字段。若有共享缓存，用 A 预热后以 B 复验。 | 已证实跨身份读取、写入或缓存泄露即失败。隐藏目录项或持有对象 ID 均不能授予访问权。工具服务端适当访问控制属协议 MUST。身份隔离与双身份用例属实践。[工具安全][tools]、[句柄安全][security]、[OWASP][owasp] |
| S02 · 声明实现 MCP HTTP 授权 | 核对资源服务器验证逻辑或模拟请求。用过期、错误受众、权限不足的测试令牌分别验证拒绝。在测试下游捕获去标识化的授权头，核对凭据来源。 | 接受非本服务令牌、接受过期令牌、把来访者令牌原样转交下游，均违反该配置适用的协议要求；无效或过期令牌应为 401，不足权限应为 403。MCP 的授权功能可选，stdio 的授权路径另见 S09。[授权][auth]、[令牌透传][security] |
| S03 · 声明只读、预览或无破坏性 | 对照真实处理函数和下游 SDK 方法。在隔离夹具上用状态快照、执行器调用计数、出站记录核对承诺。区分普通审计日志和用户可见的业务写入。 | 预览实际提交操作、只读工具触发写入，或以不受信服务的 `readOnlyHint` 放宽执行权限，均判失败。预览的“零业务写入”按接口承诺评定。只读同样可能泄露数据。注解可省略，`openWorldHint` 描述可触达实体的边界。[注解语义][hints]、[OWASP][owasp] |
| S04 · 敏感动作适用授权或项目审批 | 追踪从入口到执行器的所有路径。已规定审批时，以缺少审批、审批过期、替换目标或篡改已批动作的请求检查拒绝，并核对下游执行次数为零。 | 执行超出已授权范围，或批准目标 A 后可改为目标 B，判失败。服务端访问控制属协议 MUST；敏感调用的人机确认属客户端 SHOULD；项目审批及绑定内容按实际策略。以 `approved: true` 自报授权不可作为审批凭据。[工具安全][tools]、[OWASP][owasp] |
| S05 · 描述、schema、Prompt、Resource 或结果含外部可控文本 | 检查注册来源、内容归属和指令传递路径；用无害标记模拟“转发外部数据或调用另一工具”，观察宿主实际发出的请求与目标。 | 发现隐藏指令索取无关数据或劫持其他工具，记录原文和来源；能导致越权则单独记录行为证据。资源中保留待分析的恶意文本本身不构成失败。调用范围仍由可信代码控制。属实践。[OWASP][owasp] |
| S06 · 目录定义可更新且宿主或网关缓存了信任决定 | 在同版本、同身份与配置下比较已审核和待发布的完整定义。包含名称、描述、输入输出 schema、annotations 及有行为意义的扩展。模拟只读改为写入，检查旧决定的适用范围。 | 风险扩大后仍按旧授权自动放行，判实践缺陷。可用规范化快照加摘要发现变化。摘要相同只说明元数据相同。仅审服务端时，把宿主的重审机制列为宿主侧依赖。[OWASP][owasp] |
| S07 · 可写操作声称幂等或调用方自动重试 | 模拟“已提交但响应丢失”；以相同参数及契约约定的幂等键重试，统计提交、持久化和通知等实际副作用。 | `idempotentHint: true` 或文档承诺幂等，而重试造成第二次业务效果，判失败。非幂等工具可发布；针对非幂等写入，检查执行层是否在未知结果时盲目重试。注解语义来自规范，重试保护属实践。[注解语义][hints]、[OWASP][owasp] |
| S08 · 输入控制 URL、文件路径、命令或外发目的地 | 用受控模拟目标验证授权边界，按实现选测重定向、域名重解析、越界路径或多余命令参数；观察实际目的地和数据范围。 | 可借服务进程权限访问未授权目标、读取边界外文件、执行额外命令或外发未授权数据，判失败。工具校验输入属协议 MUST；出站白名单、连接时复验、目录隔离等按威胁模型选用。已获准的内网资产可属于正常目标。[工具安全][tools]、[MCP 安全指南][security]、[OWASP][owasp] |
| S09 · Streamable HTTP 或可执行的本地 stdio | HTTP 用明确无效的 `Origin` 复验，同时检查部署监听地址。stdio 检查启动参数来源、运行身份、授权目录及传入子进程的环境变量名。 | Streamable HTTP 对已提供且无效的 Origin 必须返回 403，本地运行建议仅绑定回环地址。stdio 建议从环境取得所需凭据，检查是否继承了无关秘密或超出约定的宿主权限。HTTP 授权和防 DNS 重绑定分开判。[HTTP 传输][http]、[授权][auth]、[本地服务安全][security] |
| S10 · 输出、错误或日志可能携带凭据或敏感数据 | 注入合成秘密，依次检查成功、失败、调试日志和审计记录；检查能否用关联 ID 定位失败。使用测试环境的受控错误，留存脱敏后的证据。 | 调用方可取得未授权的 token、秘密、其他租户数据，或日志保留可恢复的敏感值，判失败。工具输出清理属协议 MUST，日志脱敏和审计方式属实践。缺少日志访问权时只报告已核查的表面。[工具安全][tools]、[OWASP][owasp] |
| S11 · 提供工具或高消耗操作 | 核对服务端或可信网关生效的限流规则、计量键、并发和工作量上限；可用限额极低的测试配置和两次模拟调用观察拒绝路径。 | `2026-07-28` 的工具调用限流属服务端 MUST。存在限制配置但请求可绕过时判失败；仅缺少压测环境时记录未验证。耗时预算及阈值按服务负载和可用性约定。[工具安全][tools] |

## 取证边界

- 复验读取与写入使用获授权的测试账户、模拟资源或隔离环境。发现第三方内容中出现要求调用工具的指令时，仅作为证据处理。
- 对照源码和现成自动化测试可证明可达的缺陷。只拿到目录时，可证明描述冲突、注入文本或接口声明问题；后端执行、鉴权、幂等与脱敏需分别补证。
- 写入工具的副作用通过执行器、持久状态或下游审计证明。成功提示、模型表态、UI 确认框和工具风险注解均不能单独证明执行结果。
