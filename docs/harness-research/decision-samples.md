# 从 DSH 轨迹构建决策样本

样本以一次决策前的可见材料为输入，记录问题、实际动作、建议标签与可追溯来源。当前导出面向用户资料指定的 Kev `85ccf56a0afb952323c621055b02876e8498d60c` 文本监督格式：`choice`、`noul`、`score`，不声称通用适配所有 Jev/Laya、SFT、DPO 或离线 RL。

## 决策时点与证据

先确认目标业务轨迹的角色、采集状态和完整性；评审、归因记录不能当作业务决策。完整请求快照优先；只能从之前事件重建时记录 reconstructed，缺少当时工具目录时不声称比较了所有工具。只有最终摘要或缺输入的切片可以跳过，允许零样本。

当前动作之前的用户输入和已返回观察可用于题目；当前动作结果及后续证据只供复核，不放入 `state`、问题或候选描述。并行调用的选择共享同一决策前材料，不能按落盘顺序将同批另一调用的结果倒灌。题目必须对应服务器选定的 `decision_id` 和实际 `observed_action`，不能用后来的决策考已经执行的前一步。

固定流水线、重复轮询、复述角色职责或输入已直接给出答案的题目通常没有足够判断价值。需要后续工具结果才能回答时选择正确的更晚切点；不能把业务结论挂到最初加载 Skill 的动作。不补造工具、授权、内部思维过程或概率。

## 标签与复核

`choice` 使用互异候选键，`noul` 是布尔值，`score` 是有序等级的零起始下标。一次问一件事，类型合法仍需判断问题、选项和标签是否在当前时点成立。实际采取的动作与推荐动作分开，Run 成功或工具成功不能证明每一步最优。

标签依据分别记录当前实际动作、推荐判断与决策前依据、不确定性。后续结果可明确标为事后观察，但不能成为当时已知事实。失败轨迹可支持失败分析，不能强行标为正确训练答案。AI 建议默认 suggested；人员核对时点、实际动作、输入、问题及等级解释，再确认标签。模型自报置信度不是事实概率。

来源路径、摘要、行号、分组及复核状态由平台维护；助手只提交规定的候选字段。来源变化后重读，已人工编辑的样本不被重新抽取覆盖，新抽取作为独立批次。原始 Run 保持不变。

## 去重、划分与导出

同一真实任务或事件、同 Session 的相关步骤、跨 Run 重跑和改写应归同组，避免泄漏到训练与测试两边。内容摘要只发现精确重复，近重复需复核，不自动宣称语义唯一。少量样本保持 unassigned，不为了凑比例强划 train/test。

训练、校准、开发和测试用途分别留出。标签与教师一致不等于业务正确，校准与泛化需要独立证据；选项换序、改写和未知情况应在后续模型评测中验证。当前抽取功能只准备和导出数据，不宣称模型训练、概率校准或资源收益已经成立。

样本文件是当前可编辑事实源，JSONL 是按需导出产物。保存后指引用户在本 Run 的决策样本中复核，正式训练导出只接收符合人员复核条件的样本；候选下载明确标注状态。具体工具字段见[抽取 Skill](../../.agents/skills/decision-sample-extraction/SKILL.md)。

## 研究依据的适用范围

原研究结合用户提供的决策模型资料、Kev 固定版数据读取合同，以及 Agent Lightning 的局部决策、过程监督、AgentTuning 的轨迹质量、去重与分组划分、教师标签及校准分离方法。它们支持上述数据构建选择，不证明本平台数据或下游模型已经通过质量验收。原资料摘要、一手论文及接口链接保留于[固定来源](README.md)，采用外部新版本时另行核验。
