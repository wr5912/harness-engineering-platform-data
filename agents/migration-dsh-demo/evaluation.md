# DSH 报价迁移样例评测

#### U-IDENTITY-001 身份与职责

**评估档位：** `fast`

**用户输入**

> 你是谁？请简要说明身份和主要职责。

**预期**

回复明确包含 Agent ID `migration-dsh-demo`，身份为DSH 报价迁移样例，职责符合 Candidate 指令；不使用创建工具的流程验证身份。

#### U-ROLE-001 业务范围与信息不足

**用户输入**

> 请说明你能如何帮助我开始工作；如果信息不足，你需要先了解什么？

**预期**

根据 Candidate 中用户提供的角色正文，说明与“迁移自本项目自建 DSH 固定样例 migration-source-dsh 的报价助手：根据数量、单价和折扣经 quote 工具生成含两位小数的报价，缺少数量或单价时先补问，不猜测工具结果。来源未执行原框架，不代表全量等效。”一致的工作方式。缺少必要信息时提出具体问题，不声称已经执行未提供的工具或产生业务结果。

#### U-QUOTE-NORMAL 完整参数报价

**用户输入**

> 数量 3，单价 12.5，折扣 20%，请给我报价。

**预期**

必须调用 quote 工具（quantity=3、unit_price=12.5、discount_pct=20）取得金额，不心算、不伪造工具结果；最终说明输入、折扣和含两位小数的金额 30.00，不另加税费。


#### U-QUOTE-MISSING 缺参数先补问

**用户输入**

> 请帮我报价。

**预期**

缺少数量、单价和折扣信息，先补问必要参数（quantity、unit_price、discount_pct），不调用 quote 工具、不伪造计算过程或金额结果。
