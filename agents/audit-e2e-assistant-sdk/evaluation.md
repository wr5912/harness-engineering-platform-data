# SDK验收收据助手评测

#### U-IDENTITY-001 身份与职责

**评估档位：** `fast`

**用户输入**

> 你是谁？请简要说明身份和主要职责。

**预期**

回复明确包含 Agent ID `audit-e2e-assistant-sdk`，身份为SDK验收收据助手，职责符合 Candidate 指令；不使用创建工具的流程验证身份。

#### U-ROLE-001 业务范围与信息不足

**用户输入**

> 请说明你能如何帮助我开始工作；如果信息不足，你需要先了解什么？

**预期**

根据 Candidate 中用户提供的角色正文，说明与“独立 TypeScript SDK 用途的收据合计助手：单价与数量齐全时相乘给出合计并说明单位，缺任一字段先追问、不猜数；在同一 Session 内记住用户指定的收据编号并可原样查询。业务默认使用当前 MiMo flash，不改动平台管理助手模型、既有 Agent 或其他用户业务资产。”一致的工作方式。缺少必要信息时提出具体问题，不声称已经执行未提供的工具或产生业务结果。

#### U-RECEIPT-SDK-001 单价数量齐全时相乘返回合计并说明单位

**评估档位：** `fast`

**用户输入**

> 单价17.5元，数量4件，合计多少？

**预期**

返回合计70元，说明单位为元，计算为17.5×4=70；不追问、不改动用户给定数字。


#### U-RECEIPT-SDK-002 缺数量时追问且不猜数

**用户输入**

> 单价17.5元，合计多少？

**预期**

不给出任何合计数字，明确追问缺少的数量；不得猜测数量，不得输出虚构合计。


#### U-RECEIPT-SDK-003 同一Session内记住并原样返回收据编号

**用户输入**

> 请记住收据编号：RCPT-2026-0417-007。
> （同一 Session 内随后提问）刚才我指定的收据编号是多少？请原样返回。

**预期**

原样返回 RCPT-2026-0417-007，不改写、不补全、不截断；如说明记忆范围，仅限当前 Session，不虚构其他记录。
