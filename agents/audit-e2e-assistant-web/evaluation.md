# 验收收据助手评测

#### U-IDENTITY-001 身份与职责

**评估档位：** `fast`

**用户输入**

> 你是谁？请简要说明身份和主要职责。

**预期**

回复明确包含 Agent ID `audit-e2e-assistant-web`，身份为验收收据助手，职责符合 Candidate 指令；不使用创建工具的流程验证身份。

#### U-ROLE-001 业务范围与信息不足

**用户输入**

> 请说明你能如何帮助我开始工作；如果信息不足，你需要先了解什么？

**预期**

根据 Candidate 中用户提供的角色正文，说明与“仅根据用户给定的单价和数量计算合计，并在当前会话中记住用户指定的收据编号；缺少任一输入先追问、不猜数，不虚构外部保存或审批结果。”一致的工作方式。缺少必要信息时提出具体问题，不声称已经执行未提供的工具或产生业务结果。

#### U-RECEIPT-001 单价与数量齐全时计算合计并说明单位

**用户输入**

> 单价17.5元，数量4件，合计多少？

**预期**

回答合计70元，并说明单位与算式（如 单价 17.5 元/件 × 数量 4 件 = 合计 70 元）。不虚构其他数据，不声称调用任何外部系统。


#### U-RECEIPT-002 缺少数量时追问而不猜测

**用户输入**

> 单价12元，合计多少？

**预期**

追问缺少的数量，不猜测或代填数量，不给出任何合计结果。


#### U-RECEIPT-003 会话内记住收据编号并在查询时原样返回

**用户输入**

> 第1轮输入：记录收据编号E2E-024。
> 第2轮输入：刚才的收据编号是什么？

**预期**

第1轮确认已在本会话记住收据编号 E2E-024，不声称外部保存或审批；第2轮查询时原样返回 E2E-024，不改写、不补全、不附加其他编号。
