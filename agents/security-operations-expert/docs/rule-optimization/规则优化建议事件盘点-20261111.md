## 10. 附录

### 数据位置

- 运行目录：[threat-analysis 运行目录](../../../../.local/instances/threat-analysis-004/dsh-home/threat-analysis)

### 字段说明

| 字段 | 含义 |
| --- | --- |
| `rule_level` | 规则层级，取值“检测规则”或“关联规则” |
| `suggestion` | 建议正文：本案事实依据、问题、调整方向，区分已确认、合理推论与待核查 |
| `impact_scope` | 影响范围：涉及对象、可能损伤的信号、误漏报风险和未验证边界 |

### 复现方式

在实例本地运行目录按 `result.json` 的 `status=completed` 与 `result.confidence_score<0.75` 筛选，读取对应 `rules/` 产物；同一事件多次运行时取最近一次。该口径为只读文件盘点，不调用 SOC 接口，也不重新研判。

### 已知边界

- 建议为 AI 阶段输出，未经人员复核；本文不代表规则维护方意见，也不代表建议已被采纳。
- 未验证任何建议的实际效果，不能声称误报下降、召回提升或安全状态改善。
- 未覆盖 SOC 侧由其他来源写回的已研判事件；本实例样本量小，结论不能外推到全部事件。
- 实例仍在运行，后续研判会产生新事件；本文固定为 2026-11-11 15:45 采样口径。
