# 报告版式技术验证边界

这些 HTML、截图和检查结果仅来自合成离线 fixtures，未查询 SOC、未执行业务 Run，不代表真实巡检、诊断、修复或恢复结论。

- 调用数据根 mcp/src/reports 的生产纯 render 接口，不修改 Candidate、平台配置、发布、绑定或实例。
- 仅使用已有 Node24、Playwright Core 和系统 Chrome；没有安装依赖。浏览器使用新隔离临时资料目录，不读取已有浏览器资料或凭据。
- 只导航本目录本次生成的三类本地 HTML 及其内嵌 blob 打印版；禁止 HTTP(S)、其他协议及外部 file 请求。不打开用户参考附件，不执行附件脚本，不访问平台或 53105。
- 不关闭 CSP、不注入绕过脚本、不修改模板来使测试通过。CSP、JS、网络及交互失败均记录在 browser-checks.json；非零退出如实保留。
- browser-checks.json 记录合成输入和生产源码摘要、真实 Chrome 检查及技术限制。是否装载到业务实例、真实运行效果和安全语义业务通过均不在此测试范围。
- 浏览器临时文件仅位于本目录 .browser-runtime；它们不是交付证据，不读取其中状态。
