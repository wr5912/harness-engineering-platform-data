# 深度巡检设计取舍

本文件保留本组合的业务取舍；当前调用字段、依赖与算法以本包定义和源码为准。

本组合通过公开合同引用 `inspection-routine` 与 `inspection-vulnerabilities` 的固定发布版本。常规巡检作为一个子组合使用，不再次自行执行其内部检查；子组合的字段映射与实际版本由本组合定义维护，通过公开输入输出合同调用，不读取子组合目录。

汇总时保留各检查的原始归属，常规巡检的汇总数不能与其单项明细重复计数。漏洞使用已有数据，不因深度巡检启动新扫描。

常规巡检部分失败时，仍执行可独立完成的漏洞检查；结果保留各类检查的失败、不完整和未知，不能因另一个子组合成功而显示全部正常。仅在实际覆盖和数据完整性支持时形成综合结论。
