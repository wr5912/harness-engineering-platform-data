# 可达性检查设计取舍

本文件保留本组合的业务取舍；当前调用字段、依赖与算法以本包定义和源码为准。

本组合是可独立调用的工作流，也可经公开接口供其他组合复用。依据合规规则或用户明确指定的源、目的与模式核查网络路径，区分路径计算和 ACL 分析；默认核查完整路径，需要经过指定节点等业务选项由公开 Schema 与实现维护。

成功获取规则但规则确实为空时，按需补充源、目的等必要信息；规则接口失败不能当作无规则。按规则生成实际检查对，不默认对所有资产做笛卡尔积。端口、协议或 ACL 判断只使用真实接口能够提供的事实。

配置推导的可达不等于真实网络探测成功。NAT、策略或路径信息不足时保留未知，不生成确定可达结论，也不隐含发起主动探测。
