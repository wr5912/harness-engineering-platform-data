# 输入、证据与执行边界

## 唯一合同与对象

公开输入、已接SOC操作和最终分支身份以[TS入口](<../src/index.ts>)为准；当前草稿仍是有限后继的未完成改稿，不是已验收的通用证据驱动剧本，组合身份和连接以[定义](<../composition.json>)为准。只接受已确认的源/目标IP和单个协议端口；故障起点可未知，历史证据查询窗可整体省略，若提供则须成对、带时区且递增；查询窗不冒充故障起点或观测时间。不从业务名称、旧Case、NAT候选或历史探测猜对象。prepare纯校验，分别克隆输入、scope.requested和端点；resolve读取本Run已冻结输入，唯一身份失败进入独立blocked终态。

## 原生依赖分支与证据边界

[flow.json](<../flow.json>)是管理画布和执行的唯一可编辑控制源。当前为13节点、14边逐轮草稿：受理冻结→上下文预算→首轮选择→执行解析→事实追加→候选更新→四条件分支；规则和提议节点均显式回到执行节点。旧固定三路、一次告警和固定汇总屏障已移除。环内输出声明allows_loop；静态dry不证明官方运行时可正确启动、迭代和停止。事实追加与候选更新分别在对应节点执行。受控提议、固定设备可用性复用及同诊断持久续问尚未接通，明确停点，禁止发布。

当前原生图不安排TCP占位检查；协议适用于冻结的SOC读取，不把UDP转换成TCP未知。应用、当前监听、服务与日志、路由及action-defs动作未核合同与真实终端绑定时明确列能力缺口，不伪造原子或用平台执行点冒充源端；不接受模型自填结果，不发主动TCP/HTTP/ICMP，不自动修复。

组件返回前调用既有progress；记录异常向外抛出，不把失败转换成完成。事实和原回执仍由既有Run合同承载；调用顺序不替代实际落盘可见性或真实上游效果的取证。SOC调用经现有context.call共享有界额度与取消/超时，不另建调度器、执行器、存储或另一份流程DSL。

当前非code输入显式保留`show:true`；四条件只选择一个出口，报告与停点为独立终态。规则或提议校验失败后不会发上游请求，返回执行节点再经事实/候选和停点判断。历史批次模板经验不证明本图的回边调度和互斥跳过传播已验证。

正式流程运行时使用官方 LFX，组件测试只替换外部 SOC 边界。执行、真实外部取证及业务结论须分别验证，不能以流程完成证明主动原子或根因成立。

## 证据、报告与公开依赖

只调用已发现的资产、SOC状态、固定快照告警及配置路径只读操作。告警页覆盖不足或合同不明保留partial及原错误，零告警不判无故障；配置模型UNKNOWN/NO_DATA不被reachable=false覆盖，也不作为源端连接实测。每项保留来源服务/操作、查询起止、原回执及本Run/node引用；源观测和时区缺失保持unknown，不拿查询时间或evaluatedAt补观测。敏感键值脱敏。

既有artifacts输出完整UTF-8 HTML和JSON。HTML正文按对象、状态、已得证据、候选六态、轮次、缺口和下一步呈现，原始JSON仅放默认收起的details；源字符串转义。incomplete不表示修复成功；执行未知、请求失败、收到响应和未执行分开记录；从原run_id查看报告不会重新诊断，不调用Java旧诊断/报告。

公开依赖为[公共action-api.ts](<../../../src/action-api.ts>)的SOC类型与解包，以及平台提供的WorkflowContext、官方LFX/hep_lfx的HepInput/HepBatch及component/progress桥。包内body复用本包TS模块，不读兄弟组合私有文件、不引用可变子组合或另一份执行入口。程序根只作为研发测试工具依赖，不作为业务配置或临时数据来源。

## 构建交接与验证状态

[合同测试](<../tests/README.md>)核对冻结、只读边界、进度异常、分支闭包、汇总、HTML安全及中文条件标签；共享判据测试还核对时间分离、六态、冲突相关性、真实schema参数范围和未知执行不重发，业务场景回归禁止网络。历史[管理回执](<management-receipts.json>)与当前本地未保存草稿分别解释，不能把历史dry视为当前草稿。

运行时公开共享依赖包括 MCP action-api.ts、src/reports/common.ts 和 src/reports/troubleshooting.ts，以及平台 workflow/LFX 桥，不导入兄弟包私有实现。HTML 使用公共报告组件及带摘要的受信脚本；原始完整事实另存 details 产物，HTML 折叠区采用脱敏投影。唯一可编辑流程及组件源码分别位于本包 flow.json 和 src/index.ts，构建版本不是第二份编辑来源。

草稿保存、构建、dry、实例绑定、真实 SOC 调用和原生报告下载各自提供不同证据；dry 必须零上游请求。当前逐轮画布草稿已通过公开保存入口保存并回读；未发布、未绑定，真实循环调度未验证；外部验收此前真实受理失败原始回执为`ai-soc-master/list_soc_asset` 400，OpenAPI匿名HTTP 502，不能解释为无资产或无能力。对外使用先核对当前实例来源和绑定版本，异步启动后按真实Run查询，未知启动结果不自动重放。未实施完整候选驱动循环、持久续问、监听/服务/采集绑定动作目录或主动探测。
