# 常规巡检设计取舍

本文件保留本组合的业务取舍；当前调用字段、依赖与算法以本包定义和源码为准。

本组合通过公开合同引用 `inspection-baseline` 与 `inspection-reachability` 的固定发布版本。状态证据已随同次资产范围返回，由本包内部节点汇总，不增加接口调用，也不另设状态组合。具体映射与版本由本组合定义维护，不导入其他组合私有实现。

只进行日常状态、基线和可达性核查，不隐含漏洞检查、新扫描或主动网络探测。作为其他流程的子组合时仍保持同一业务范围。

某项失败后继续其他可独立完成的检查，汇总全部子结果并保留失败与未知；不能使用最后一个子结果覆盖整体结果。每类检查在本次常规巡检中只执行一次。
