# Decision

状态：inconclusive

## 本轮结论

在本特性分支保留新增网络空间监控实现，不声明完整实际生效或业务验收完成，不合并主线。原聊天插件、模型与语音配置未改；新监控使用独立入口与默认沉浸式覆盖，真实只读查询不以原型模拟值补缺。

[实施观察](evaluation/observations.md)记录了源码保存、语法/平台合同检查、23项纯函数测试、管理端真实上游读取、用户后续授权创建独立实例的回执，以及一次受控浏览器视觉验证。这些证据分别判断，不以保存、离线测试或端口启动代替实际装载和真实数据业务通过。

## 浏览器验证后的状态

当前会话未提供 Playwright 包或注册的浏览器控制工具，且工作区规则不允许临时安装依赖。使用系统 Chrome 149 的一次性 CDP 会话访问统一网关，已经实际打开监控入口并截图：默认沉浸式不透明视口、空数据明确状态、拓扑不补演示节点和“返回聊天”均得到 DOM/截图证据。返回操作关闭监控对话框并回到原生 AI-SOC 页面，未切换会话。

首次浏览器检查发现 MCP SDK 错误对象被原地写入只读 `status`，导致 `Cannot set property status of Error which has only a getter`。已改为可写包装错误；修复后23项测试和 `research/validate` 均通过，浏览器不再出现该 JavaScript 错误。目标实例随后明确显示 `CLIENT_HTTP_AUTHENTICATION` / HTTP 401，说明实例侧 MCP 认证/配置仍未就绪，界面正确保持 unavailable/unknown，而非模拟成功。截图由 Chrome CDP 生成，不称为 Playwright或生产接入通过。

## 实例创建后的状态

独立实例 `network-space-027-r6930a1922fdc` 已创建并运行，来源与挂载均为本分支，模型为 local / Qwen3.8-27B；采用统一网关的 anonymous/development 方式，没有操作其他实例。

当前 `asset_status=unknown`、`loaded=null`。日志明确报告继承的 `instance-confirmation-config` 入口因专用配置未就绪而未激活；错误尚不能区分不存在、权限或内容不合格。只读核对了插件源码和 reload 预览，没有读取或复制私钥、生成签发材料、禁用保护或无条件重载。一次有授权的 reload 返回结果未知，回读仍无加载回执；没有重复重载。

管理端对目标监控接口的 web_fetch 尝试被工具的内网地址限制拒绝，未得到目标接口业务回执；没有改用其他通道绕过该限制。浏览器通过目标实例自身页面拿到的401是实例侧真实返回，不与管理端成功源读取混淆。

## 保留的反例与限制

设备与含软件的图谱节点口径不同；上游按日趋势与精确24小时列表不能直接对账；原始规则主张可能对应最终误报。界面应保留来源、采样、未知、部分/过期状态与历史结论，不把布局或动效当作攻击、检查通过或实际执行证据。

原先的401探测已被后续目录更新后的成功源读取补充，不能继续当作当前全部数据不可用的结论。本轮未启动业务评测Run，也未与当前主线或并行分支做效果比较，不能据此排除它们的能力或声称本分支更优。
