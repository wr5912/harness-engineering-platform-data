# EXP027 三特性主线融合

将用户指定的威胁研判、策略应急与巡检资产纳管特性合入当前同代主线，研究它们能否在保留 DSH 原生委派、确认、调度及工具展示的前提下共同工作。固定来源、特性取舍和构建身份见 [change.yaml](change.yaml)，融合后的验证结果见 [evaluation/observations.md](evaluation/observations.md)。

融合保留来源的业务接口与错误语义：威胁研判使用本地报告和原始校验状态；XX 设备指令与模板走已核实的真实来源；巡检、只读故障、完整报告和资产纳管保持各自来源及确认边界。来源中的旧确认器、处置循环、子会话续接与按业务锁定的包装不覆盖主线原生能力。

可证伪条件是融合后来源路由错误、既有业务合同回退、报告与校验状态失真，或固定资产不能构建和装载。离线回归只验证合同与受控夹具；实际装载和真实业务用例须使用融合后的新 Run 另行核对。当前不依据来源分支的历史结果直接作采纳结论。
