# 安全巡检

先按[查询与执行的选择](references/workflows.md)区分简单查询、语义分析和完整巡检。查询巡检项只读取当前工具描述与 Schema；查询单台设备状态等已有事实，通过现有只读工具路线办理；读取已有结果和管理周期任务分别使用现有查询工具和原生 Schedule，不启动巡检组合。需要固定的数据衔接、覆盖检查和汇总报告时，才按当前工具目录及 Schema 选择基线、漏洞、可达性、常规或深度巡检。状态事实查询直接使用原始只读工具，常规和深度巡检内部复用同次状态证据。

目录查询、介绍和预览不启动运行；需要新近目录时使用原生 MCP 工具发现能力。影响咨询和明确“不执行”“只预览”的限制优先，不能尝试启动后再靠拒绝结果证明未执行。巡检读取 SOC 已有事实，不进行主动扫描、修复或响应处置。

用户先询问有哪些设备时，由主助手按[包内分流表](references/workflows.md)通过当前发现的资产只读工具取得候选，不以空的 MCP 资源目录代替设备查询。保留用户筛选、真实设备身份、类型与归属、查询来源与时间、分页边界和缺失字段；不得创建诊断或巡检运行。查询失败或没有候选时如实保留缺口；取得候选后，在会话中保留展示顺序与真实身份，用户选择“第一台”等指代时绑定对应记录，不要求重抄已知 IP，也不扩大范围。

## 范围与执行

“创建巡检任务”等表述未明确即时执行还是周期任务时，只补问执行方式及缺少的巡检内容、范围；周期任务再补周期。保留已经明确的信息，不默认周期任务，也不要求用户重新填写完整表单。

预览后的“确认执行”沿用最后选定的内容与范围；已取得运行回执后再次确认只续查原运行。用户取消尚未执行的请求后，该意图不再有效；其后仅说“确认执行”时须重新明确任务，不能沿用已取消内容，也不能尝试启动来判断是否允许。

用户明确执行完整巡检且内容、范围完整时，同轮调用相应巡检组合，不要求再次确认；单纯查询事实仍沿用查询路线。范围按工具 Schema 传入 `scope`：常规巡检未指定范围时默认 `scope.all=true`，同轮执行；用户明确全部资产时使用 `all: true`；指定编号、IP、网段、类型、层级或部门时保留原筛选，各字段取交集，不扩大为全部资产。其他需要范围的单项缺少范围时只补范围；非法值、未命中或读取失败不能扩大范围。目录或错误中的内部字段不让用户代填。可达性优先使用启用规则；确需指定业务连接时，仅补真实缺少的源、目的及其他必要参数，不能把规则读取失败当作没有规则。用户明确按“全部适用规则”执行业务互联专项检查（可达性）且未缩小设备范围时，规则范围已完整，按工具约定使用 `scope.all=true` 同轮执行当前启用规则，不重复索要设备范围或源、目的地址；用户已给出的设备筛选仍须保留，不能因“全部适用规则”扩大设备范围。规则范围与设备范围分别解释，以同次运行实际覆盖为准。

运行身份由受管插件绑定真实会话及用户或原生定时消息，模型不生成执行编号。组合连续完成范围冻结、分页、子检查、返回数据加工及可确定的异常恢复；常规和深度巡检复用已发布的固定子版本。助手负责理解请求、选择流程、补充必要信息、反馈进度和解释结果，不逐资产或逐接口重复调度已有组合。成功回执取得真实 `run_id` 后，只查询该运行；受理、执行完成与业务结果完整分别判断。提交回执不明时核对原运行，不能换参数或另发启动来碰运气。补充信息保留原输入；错误只阻塞受影响能力，其他业务继续。

## 结果与报告

实际调用组合后，用发现的 `get_composition_run` 查询原 `run_id`。取得受理回执后先告知当前状态及真实运行标识，再续查原运行至终态并交付同次报告，正常短任务不能在 `accepted` 就结束，也不能因连续查询几次仍在执行就停止跟踪；长任务确实尚未完成时，如实报告当前状态、原运行标识及后续查询入口，不声称自动跟进。读取同次返回的范围、检查摘要、异常、未知、失败和未覆盖项；`completed` 只表示执行结束，不能将未知、失败或不适用说成正常。设备数、规则数和检查项数分别说明，保留真实证据及整改建议。

摘要以同一 `run_id` 的 `get_composition_run` 回执为依据；确需明细才调用 `get_composition_details`，使用真实返回的节点标识并按页读取，不为凑摘要查询猜测的节点或把空页当作没有检查结果。

报告就绪或用户要求完整报告、报告下载时，优先由主助手直接调用 `export_security_report`，传 `kind: "inspection"` 和本会话真实原 `run_id`；该入口读取同次HTML产物并保存原始字节。不要先用 `get_composition_artifact` 把整份HTML送入模型再导出；用户显式要求正文或确需核对字段时，仍保留原报告的按需读取能力及原工具输入契约。不能用Markdown或模型重写正文代替HTML，也不为下载重跑巡检。生成或保存完整文件不等于模型阅读全文；只读摘要、分页或spill片段时，如实说明实际读取范围。

成功后交付本次报告卡片，可“预览HTML”或“下载HTML”。当前下载控件位于折叠的执行过程内，应提示用户展开本条“执行过程”→“已调用工具”后点击“下载HTML”；不虚构直接URL。回复可引用真实 `file_path`，不得将本机路径冒充网站URL或自行拼接HTTP地址。工具报未就绪、来源不符或读取失败时如实说明，不虚构文件或下载成功。下载后的报告保留原巡检范围、时间和未知项，文件生成不等于巡检全量正常。观测时间保留回执中的日期、时间和时区，未提供时区时不自行补写或换算。续查沿用原运行身份，说明本次读取范围与剩余页。

## 周期任务

内容、范围与周期完整且原生 Schedule 可用时，直接创建周期任务，保留原始范围和执行意图；每次到期重新解析当时资产，不把一次快照固定为后续范围。核对真实任务标识、周期和下次时间，创建成功不等于已经巡检。只接受可追溯的真实到期消息；同次到期续查原运行，不重复启动。未取得真实到期及巡检回执时，明确自动执行尚未验证。
