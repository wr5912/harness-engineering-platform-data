# Decision

状态：adopt

采纳本 Experiment 的威胁研判提示修订，用于已暴露的输出合同问题；范围限本研究的基本模拟五源事件和 DeepSeek Flash/max。完整继承的其他业务能力未据此重新宣称通过，也不自动切换任何现有业务实例来源。没有创建 Research Release。

最终 Candidate 使用原校验器，连续两次真实模型调用均为 passed 且 warnings=[]：一次分别执行四阶段，一次通过已发布父组合调用四个子阶段。两次均完成模拟 SOC 回写、报告保存和 HTTP 200 下载，快判路线仍不调用模型，见 [Evaluation](evaluation/observations.md)。前轮的失败、警告和原始响应全部保留。

这不是严格单变量 A/B：各轮由独立 Mock 进程重新取证，业务输入归一化采集耗时后相同；并未把同一字节的失败冻结输入重新送入两版模型。平台旧固定算法和本 Candidate 继承的 MCP 客户端存在差异，不能只凭全过程结果把改善完全归因于提示词。旧校验器仍存在分类标签措辞的词法误拒限制；本修订调整证据表达，没有修复该校验器的通用语义判断能力。没有证明跨威胁类型泛化、业务 off 模型效果或其他完整业务任务。

接入次序：先将本完整 Candidate 与真实证据固定为新的 Git 提交，再由平台组合扩展显式引用该提交及路径，并对新父版原生 MCP 网关适配、只读缓存、四阶段等效和历史结果读取做回归。平台算法引用升级属于独立接入改动，不修改既有 3081/3084 Harness 或其 MCP 配置。
