# 原生通知code实际装载验收

技术范围：使用受控TypeScript构建的新工作流SDK，在独立官方SDK实例内实际spawn受管理子会话。主图只委派一次并回复“已委派”；子图真实等待1.2秒后完成本地确定性计算，原生subagent-settled应触发根后续本地文本交付。

固定检查：根首turn/end早于子终态、后续根响应与SDK完成晚于子终态；只有根首轮和子首轮各执行一次真实图，通知回合没有新图、委派或模型请求。随后同来源恢复会话，普通用户输入仍正常入图一次。所有来源与实际事件保持可复核。本技术probe不是业务效果比较或算力采纳；hybrid模型角色采用已核对的研究配置但本图没有infer/decide调用。
