# 多步骤业务资料调研报告

## 资料 1

autoresearch 的业务用途是自主 LLM 训练研究：把一个小而真实的 LLM 训练环境交给 AI agent，让它在夜间自主做实验。执行方式是 agent 修改代码、训练 5 分钟、检查结果是否改善，保留或丢弃，再重复；人第二天早上得到实验日志和（希望）更好的模型。训练代码是 nanochat 的单 GPU 简化实现。三个关键文件：prepare.py（固定常量、一次性数据准备即下载训练数据与训练 BPE tokenizer、运行期工具如 dataloader 与评估，不修改）、train.py（唯一由 agent 编辑的文件，含完整 GPT 模型、Muon + AdamW 优化器和训练循环，架构、超参、优化器、批大小等都可改）、program.md（给人的基线指令，由人来编辑迭代；README 称其本质是一个超轻量 skill）。人不再直接改 Python 文件，而是编写 program.md 来为 agent 提供上下文并搭建自主研究组织。执行边界与度量：训练按固定 5 分钟时间预算（墙钟，不含启动/编译）运行，与算力大小无关；指标为 val_bpb（验证 bits per byte），越低越好且与词表大小无关，便于公平比较架构改动。设计取舍：只改一个文件使范围可控、diff 可审阅；固定时间预算带来约 12 次实验/小时、睡眠期间约 100 次实验，使不同改动可直接比较并找到该平台该预算下的最优模型，代价是结果无法与其他算力平台上的人比较；自包含，除 PyTorch 和少量小包外无外部依赖，无分布式训练、无复杂配置，一 GPU、一文件、一指标。使用条件：需要单张 NVIDIA GPU（在 H100 上测试）、Python 3.10+、uv；运行方式为 uv sync、uv run prepare.py（一次性约 2 分钟）、uv run train.py（约 5 分钟）。README 说明当前只支持单张 NVIDIA GPU，CPU/MPS 等其他平台原则上可行但会增加代码体积，作者暂不亲自承担；针对小算力设备建议使用列表中提到的 fork（macOS、Windows RTX、AMD 等），并给出为更小模型调参的建议：换用熵更低的 TinyStories 数据集、降低 vocab_size、降低 prepare.py 中的 MAX_SEQ_LEN 并相应调整 DEVICE_BATCH_SIZE、降低 EVAL_TOKENS、在 train.py 中降低 DEPTH（默认 8）、改用 WINDOW_PATTERN "L"（SSSL 的交替带状注意力可能很低效）、大幅降低 TOTAL_BATCH_SIZE 并保持 2 的幂。运行 agent 的方式是在仓库中启动 Claude/Codex 等并关闭全部权限，提示其阅读 program.md 开始实验。许可为 MIT。

## 资料 2

EvoFlow 的业务用途是面向长任务的原生 Agent Runtime 与控制平面，由 EvovexAI（景银泰）打造：规划、拆解、执行、恢复与交付，多 Agent 协作全程可观测、可干预。它把长任务交给可协作的 Agent Teams：先澄清与规划，再在隔离上下文中执行工具与沙箱作业，失败可恢复，过程可验收；控制平面覆盖对话、Plan、Goal、任务中心、工作流与可观测性。能力清单包括：对话/Plan/Goal（日常协作，先出可修订计划再执行，长任务后台挂起）；Agent Teams 与智能体员工（多 Agent 分工、岗位值班与关键审批、汇报）；应用中心/自动化（多节点固定业务工作流产品化，定时与 IM 派发）；工作空间与代码索引（项目目录边界，符号/引用图谱供 Agent 检索）；自我进化（资产中心：经验沉淀、反思过程、画像与记忆）；治理套件（多账号/SSO、费用统计、运维观测、安全中心）；资源市场（资源包与扩展应用安装，技能与 MCP 扩展能力）；沙箱与可观测（隔离执行，任务、工具调用与用量可见）。执行方式有两种：一是桌面安装包，从 Releases 下载安装，打开应用后在设置→模型添加服务商与 API Key，测试后设为主模型，然后开始对话，复杂任务用 Plan、长任务用 Goal；macOS 可能提示已损坏或无法验证，因为尚未 Apple 公证，需执行 xattr -cr /Applications/EvoFlow.app 或在系统设置→隐私与安全性→仍要打开。二是从源码运行，适合二次开发、贡献代码或自托管：克隆仓库后复制 config.example.yaml 为 config.yaml（涉及沙箱/工具/渠道等，模型在启动后的界面配置），依赖 Git、Python 3.12+、Node.js 22+、uv、pnpm 9+，执行 make check && make install && make dev，Windows 用 scripts/windows/dev-stack-isolated.bat，启动后打开入口地址在界面完成模型配置再验证对话。平台为 Windows、macOS、Linux。使用边界与授权：版权 © 2026 景银泰（EvovexAI），采用 PolyForm Noncommercial License 1.0.0，属于源码可见（source-available），允许个人学习、研究与非商业使用，商业使用须书面授权（cloud@evovexai.com），并明确声明本许可证并非 OSI「开源」许可证；第三方组件见 NOTICE，商业化与第三方许可证（含 zcode Apache-2.0）对 EvoFlow 的具体影响见 docs/legal/zcode-license-impact.md，作者与贡献者权利见 AUTHORS.md 与 CLA.md。参与贡献需先读 CONTRIBUTING.md、同意 CLA.md、遵守 CODE_OF_CONDUCT.md，安全问题按 SECURITY.md 私密报告、勿在公开 Issue 中粘贴密钥。支持项目为自愿打赏，不影响使用与授权，打赏不构成商用许可，商业合作或定制联系 cloud@evovexai.com。EvoFlow 自述为独立产品，开发中参考了 DeerFlow、Hermes Agent、OpenClaw、OpenAI Codex、LangGraph/LangChain、MCP、Tauri 等项目的设计思路，并 vendored/借鉴了 ZCode（Z.AI Co., Ltd.，Apache-2.0）的部分 UI、协议与服务代码。
