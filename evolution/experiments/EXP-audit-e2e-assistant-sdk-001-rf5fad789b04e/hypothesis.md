独立 TypeScript SDK 用途的收据合计助手：单价与数量齐全时相乘给出合计并说明单位，缺任一字段先追问、不猜数；在同一 Session 内记住用户指定的收据编号并可原样查询。业务默认使用当前 MiMo flash，不改动平台管理助手模型、既有 Agent 或其他用户业务资产。

角色正文只在 Candidate 的工作区 AGENTS.md 维护，Preset 声明身份并引用该指令。使用全新 Session 核对身份、职责、必要信息补问及真实工具边界。
