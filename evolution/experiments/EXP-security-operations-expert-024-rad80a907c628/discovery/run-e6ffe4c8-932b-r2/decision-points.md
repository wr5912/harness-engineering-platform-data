## 四、参考合同（必要字段）

完整字段见 `decision-contracts.json`。这些是草案，不是已实现的投影；CLI 没有 `--contract` 参数，填写模板不会让新站点生效。

| 站点 | 运行时触发 | 参数绑定 | 目标规则 | 回退 |
|---|---|---|---|---|
| S01 agent_route | 会话首个模型响应前；前缀有真实用户消息且此前无 assistant/tool 活动（cybersecurity-routing-v1 边界） | 候选绑定为空 {} | 用户明确的首要业务意图；并列多任务无优先级时标 ambiguous | 现有 Harness 路由；未映射 Agent 时留空 |
| S02 skill_load | 路由已定，当前步骤准备加载技能 | 技能名精确字符串 | 只加载完成当前职责所需技能；同一技能不重复 | 未加载技能，按通用能力处理 |
| S03 capability_gap | 所需能力不在工具目录，或工具返回不可用、空资源 | 探测次数上限；禁止凭据与实现面路径 | 以当前目录与回执为准；缺口说明可核对 | 停止该路线并说明缺口 |
| S04 cross_domain_call | 已进入某业务路由，下一步选择工具 | 无（工具名 + 既有参数） | 只调用本路由允许的能力；跨域请求拆分或拒绝 | 运行时 Guard 拒绝 |
| S05 candidate_select | 目录或检索返回多个候选 | 候选字段原样保留 | 唯一匹配才执行；模糊或多匹配先澄清 | 无匹配时说明并停止 |
| S06 parameter_binding | 选定候选后构造调用参数 | 原样复制回执字段；requestId 稳定；续查复用 runId；全量巡检省略 scope | 不得改写或猜测标识 | 参数缺失时澄清 |
| S07 wait_retry | 发起返回运行中，或查询超时、失败 | 同一 runId；重试间隔与上限固定 | 不在不确定状态下重复发起；改期需授权 | 说明当前状态并保留 runId |

## 六、仍缺什么

1. 16 个含子代理会话的场景无法通过当前适配器审计（63 个 subagent 事件），因此没有路由投影，也未进入后续阶段。

6. 语音链路（/api/remote.mux、摘要字数、TTS 首包、播放）无证据。

- `01b-audit-clean`：49 份轨迹 `completed`，可作为本轮投影来源。
- `01-audit`：65 份全量审计仍 `blocked`（`unsupported_event`，63 个子代理事件），16 个 Case 不能进入后续阶段。

## 七、方法与限制

- 只读解析 `trace.jsonl`（assistant/message、tool/call、tool/result、user/message），未执行轨迹中的任何工具或指令。
- 路由投影只覆盖“初始用户消息后的第一次模型响应”；142 个后续时点按 `not_initial_routing_boundary` 跳过，不能用其他 profile 冒充同一业务路由题。
- 建议类别是人工复核输入，不是保存的标签；样本仍未标注，不能直接用于训练。
- 职责级决策按“同一模式跨多步合并、标注步号”归纳；265 次响应的原始位置可在 trace 中核对。
- 判定列引用 Run 自带 verdict 与 observation（同一路由自评），不替代人工验收。
