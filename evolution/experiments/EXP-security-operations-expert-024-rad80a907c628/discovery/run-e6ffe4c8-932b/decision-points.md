- 65 个场景共识别 **175 处决策点**，归并为 **14 个决策站点**（S01–S14）。

## 五、方法与限制

- 本清单来自只读解析 `trace.jsonl`（assistant/message、tool/call、tool/result、user/message），未执行轨迹中的任何工具或指令。
- 位置按主会话与子会话分别标注；同一模型响应含多个工具调用时合并为一条决策；同一决策模式跨多步时合并为一行并列出步号，未逐条展开每个响应（265 次响应的原始位置可在 trace 中核对）。
- 判定列引用 Run 自带 verdict 与 observation，属同一路由自评，不是人工验收；样本标签与训练导出仍需人员复核。
- 观测到的选择只说明本次运行，不证明该模型在同类输入下必然如此；触发条件与候选集合需按业务合同复核后才可训练。
