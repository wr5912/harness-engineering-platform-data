# 产品能力说明

## 已实现能力

- 支持 LDAP 和 OIDC 中的任意一种配置，当前演示环境已验证 OIDC；
- 支持资产、告警、策略、巡检和审计对象的统一管理；
- 支持按项目和角色进行数据隔离；
- 支持操作日志、审批记录和工具调用记录；
- 当前版本支持 Markdown 和 DOCX 导出；PDF、HTML 和其他发布包不属于当前 HTML 验收基线；
- 支持不少于 20 个标准巡检项；
- 支持 5 类基础报表模板。

## 规划能力

- 15,000 资产容量需要专项压测；
- 99.9% 月度可用性需要结合部署环境和合同条件确认；
- 自动形成最终报价不属于当前版本能力。

## 事实边界

本文件只允许证明上述范围，不得将规划能力描述为已完成或已经通过测试。
