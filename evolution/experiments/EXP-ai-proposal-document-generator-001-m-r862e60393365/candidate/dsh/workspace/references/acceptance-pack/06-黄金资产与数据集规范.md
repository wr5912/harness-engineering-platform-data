# 06 黄金资产与数据集规范

## 1. 五类黄金资产

| 资产 | 职责 |
|---|---|
| 黄金法则 | 定义必须做什么、禁止做什么 |
| 黄金标准 | 定义什么才算正确、安全、完整、可发布 |
| 黄金案例 | 定义可复现、可验证的真实任务 |
| 黄金答案 | 定义参考结论、目标状态、证据要求和允许变体 |
| 黄金数据集 | 将案例和结果契约版本化，支持回放、回归和门禁 |

## 2. 黄金法则示例

~~~text
事实与推断分离：没有来源的内容必须标记为推断、建议或待确认。
关键主张有证据：正式发布的关键主张必须绑定可定位证据。
版本优先：补遗和新版本生效后，旧版本不能静默覆盖。
失败真实：工具失败、超时和证据缺失不得输出成功结论。
发布受控：存在关键漏项、证据缺失、格式错误或未审批承诺时不得发布。
变更可追踪：影响分析必须列出受影响要求、章节、证据和评审。
人工升级：法律、报价、重大承诺和高风险内容需要人工确认。
~~~

## 3. 黄金案例最小卡片

业务团队只填写：

~~~markdown
## 案例名称

## 用户要解决的问题

## 当前已知情况

## 希望系统怎么处理

## 禁止做什么

## 怎样算处理正确

## 参考来源
~~~

平台后补风险等级、权限、工具、状态、验证器、评分规则、数据集和版本。

## 5. 数据用途隔离

- 训练数据；
- 调优数据；
- 回归数据；
- 发布门禁数据；
- 隐藏检查数据；
- 线上候选数据。

发布门禁数据和隐藏检查数据不能直接用于调优。

## 6. 生产反馈闭环

~~~text
生产轨迹
 → 失败或漂移发现
 → 脱敏和去重
 → 专家复核
 → 候选案例
 → 回放确认
 → 纳入回归集
 → Harness 修复
 → 评测和审批
 → 灰度发布
~~~

禁止自动修改黄金法则、发布门禁和高风险审批等级。
