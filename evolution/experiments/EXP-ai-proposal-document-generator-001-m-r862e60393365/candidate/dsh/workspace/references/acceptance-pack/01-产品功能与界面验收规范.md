# 01 产品功能与界面验收规范

## 1. 首屏原则

首屏必须回答：

1. 正在做哪个项目、哪一份文档？
2. 当前有哪些阻断项和待确认事项？
3. 下一步应该做什么？

产品默认进入项目文档工作台，不默认打开空白聊天框。

## 2. 页面和功能模块

| 模块 | 核心对象 | 必须支持的交互 | 验收证明 |
|---|---|---|---|
| 项目工作台 | 项目、文档、版本、角色 | 创建投标/设计项目，切换版本，显示材料、要求、证据和阻断项 | 项目状态、版本和审计记录 |
| 材料中心 | 文件、图片、扫描件、补遗 | 导入、OCR、表格识别、来源、哈希、版本、冲突、基线冻结 | 原始文件、解析结果、冲突报告、基线 manifest |
| 要求与评分矩阵 | 原子要求、评分项、格式规则 | 来源定位、分类、章节分配、责任人、验证方式、未响应筛选 | 需求台账、评分矩阵、来源截图 |
| 能力与证据库 | 能力、案例、资质、测试、人员 | 有效期、适用范围、可信等级、插入引用、禁止越界复用 | 证据登记表、主张—证据链 |
| 方案设计中心 | 场景、约束、方案、ADR、风险 | 方案比较、设计权衡、架构模型、需求和验证绑定 | 方案决策、架构模型、验证矩阵 |
| 文档工作台 | 章节、段落、图表、引用 | 章节生成、局部重写、原文对照、锚点、锁定 | 章节版本、引用、变更差异；编辑器优先复用成熟开源组件 |
| 评审中心 | 缺陷、批注、责任人、状态 | 合规、事实、技术、评委、出版评审，分派、关闭、复核 | 评审记录、缺陷单、批准记录 |
| 发布与归档 | 发布包、审批、导出物 | 门禁、Markdown/DOCX 下载、版本和回滚；其他导出格式必须另行批准 | release manifest、输出哈希 |
| 评测与治理 | 黄金任务、模型、Prompt、规则 | 回归、版本对比、失败分析、审批、灰度和回滚 | 评测报告、审计轨迹、发布结论 |

## 3. 四个关键界面

### 3.1 要求追踪视图

固定显示：

~~~text
来源条款 | 原子要求 | 当前响应位置 | 证据/验证
~~~

点击来源打开原始页，点击响应跳到文档段落，点击证据打开来源版本和有效期。

### 3.2 证据审计视图

显示：

~~~text
主张内容 | 证据来源 | 页码 | 适用范围 | 有效期 | 责任人 | 状态
~~~

证据不足、过期或越界时，必须标记并阻止正式发布。

### 3.3 变更影响视图

显示：

~~~text
变更来源
 → 受影响要求
 → 章节段落
 → 图表/表格
 → 评审问题
 → 发布包
~~~

变更必须逐项接受或拒绝，不能静默覆盖。

### 3.4 发布门禁视图

显示：

~~~text
严重问题 0 / 高风险 2 / 待确认 4
~~~

每项问题必须可定位、可分派、可修复、可关闭和可复核。

## 4. 页面验收重点

### 材料中心

- 支持 PDF、DOCX、XLSX、PPT、图片和扫描件；
- 显示 OCR、表格和版面解析质量；
- 保存文件哈希、来源和版本；
- 识别补遗覆盖关系；
- 标记冲突；
- 支持基线冻结；
- 解析失败可以重试和人工修正。

### 要求与评分中心

- 生成原子要求；
- 区分强制、评分、建议、格式和交付要求；
- 保存文件、版本、页码、段落或表格坐标；
- 分配章节、责任人和验证方式；
- 支持未响应、证据缺失和阻断筛选。

### 文档工作台

- 支持章节级生成和段落级重生成；
- 当前章节显示要求、评分、证据、风险和待确认项；
- 支持原文对照；
- 支持图表和架构图；
- 支持段落锁定；
- 支持差异对比；
- 支持本节验收状态。

### 发布中心

- 发布前执行硬门禁；
- 阻断关键问题未关闭的发布；
- 检查目录、页码、页限、附件、图表、签章位和引用；
- 当前 HTML 基线只输出 Markdown 和 DOCX，并生成可追踪的下载记录；PDF、HTML、矩阵和证据包属于正式产品的独立输出范围，不得在本 HTML 原型中冒充已实现；
- 生成版本清单并支持回滚。

## 5. HTML 静态界面验收对齐

本材料包的界面验收必须打开 `html/方案文档生成工具-静态验收原型.html`，并按照 `html/HTML-验收基线.md` 和 `html/HTML-验收测试清单.md` 执行。

HTML 界面验收的固定要求：

- 文档内容默认中文优先；
- 文档前部存在图索引和表索引；
- 图 3-1、图 3-2 直接由 Mermaid 源码渲染；
- Mermaid 图形使用无边框模式，节点按文本自适应；
- 正文存在表 3-1 要求与证据映射表；
- Markdown 模式支持源码编辑和实时渲染；
- 框选正文后出现 AI 优化选中文本浮框；
- 只验收 Markdown 和 DOCX 下载。
