# 03 验收指标与质量门禁

## 1. 指标口径必须冻结

每个指标必须提前定义：

- 名称；
- 计算公式；
- 分母；
- 数据集版本；
- 文档类型；
- 抽样方法；
- 标注规则；
- 置信区间；
- 失败等级；
- 目标阈值；
- 例外处理。

## 2. 建议初始基线

| 指标 | 建议门槛 |
|---|---:|
| 关键强制条款召回率 | 100% |
| 一般原子要求召回率 | ≥95% |
| 评分项覆盖率 | ≥98%，关键项100% |
| 来源定位正确率 | ≥98% |
| 关键主张证据支持率 | 100% |
| 数字、日期、资质编号错误率 | 0 |
| 需求—章节—验证双向覆盖率 | ≥95%，关键需求100% |
| 变更影响召回率 | ≥95% |
| 规则检查通过率 | 100% 或有审批例外 |
| 渲染缺陷 | 0 |
| 审计完整率 | 100% |
| 失败识别正确率 | 100% |
| 结构化结果重放一致性 | 100% |
| 发布包完整率 | 100% |

这些是建议基线，不是脱离数据集和环境的通用行业承诺。

## 3. 关键公式

### 关键强制条款召回率

~~~text
正确识别的关键强制条款数量
÷
专家标注的关键强制条款总数
~~~

### 证据支持率

~~~text
具有有效、适用、可定位证据的关键主张数量
÷
正式发布版本中的关键主张总数
~~~

### 变更影响召回率

~~~text
正确识别的受影响对象数量
÷
专家标注的受影响对象总数
~~~

## 4. 硬门禁

以下任意一项失败，整体不得通过：

- 关键强制条款漏项；
- 关键条款无法回溯来源；
- 正式文档出现无依据的关键承诺；
- 关键数字、日期、版本或资质信息冲突；
- 失败被显示为成功；
- 跨项目数据泄露；
- 未经审批发布高风险内容；
- 导出文件缺页、乱码、截断或丢附件；
- 审计记录缺失；
- 补遗影响未被识别；
- 关键需求未验证却被标记为已满足。

## 5. 加权评分

| 领域 | 权重 |
|---|---:|
| 材料接入和基线管理 | 10% |
| 要求与评分解析 | 15% |
| 需求—章节—证据追踪 | 20% |
| 受控生成和事实准确性 | 20% |
| 方案和图表编排 | 10% |
| 评审、缺陷和变更管理 | 10% |
| 导出、发布和归档 | 5% |
| 性能、稳定性和可用性 | 5% |
| 安全、权限和审计 | 5% |

建议总分达到 85 分且所有硬门禁通过，P0/P1 缺陷为零。

## 6. 性能指标示例

必须绑定文档规模和环境：

~~~text
在 200 页混合 PDF/DOCX/XLSX、4 vCPU/16GB RAM、
固定模型、并发 1 的环境下：

- 导入任务 P95 启动反馈 ≤ 5 秒；
- 解析任务 P95 完成 ≤ 10 分钟；
- 5 页章节生成 P95 ≤ 120 秒；
- 50 页文档导出 P95 ≤ 60 秒；
- 失败任务 ≤ 5 秒显示失败状态。
~~~
