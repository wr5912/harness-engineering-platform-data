name: policy-configuration
description: 查询可配置设备，以策略变更组合完成单条或批量策略的真实预览、原 SOC 草稿与授权下发，并查询或恢复原任务。
---

固定多接口调用链使用 `mcp__policy-response-acceptance__policy_change`；咨询、发现和独立原号查询仍使用 `policy-response` 原始工具与资源。工具可用性以本会话实际工具清单及 inputSchema 为准；resources/templates 目录与工具目录独立，资源为空不能据此断言工具缺失。工具已提供时按其合同调用，不为证明工具存在读取资源目录；GET 以资源模板提供时先发现再读取。组合尚未装载、合同缺失或失败时，报告准确停点；不得绕过组合逐步重复发现合同、预览、建任务、提交和下发的固定链，不改走旧策略服务或自建业务台账。

1. **先分清意图。** 仅询问有哪些设备、厂商或支持范围时，只查询可下发目录并列出相符设备，到此结束；目录未提供的信息标为未知，不为补齐介绍遍历每台设备配置。用户从已有候选中选定设备后复用同一身份和有效结果，只有真实歧义或关键缺项才询问，不要求重新抄录已有信息。咨询、发现和取消不构成写入授权。
2. **固定完整业务输入。** 提取指定设备、源、目的、协议、端口、操作、允许或阻断效果及原因；组织名称只作候选筛选条件，多条请求保留全部范围。普通源/目的 IP 不强制逐个解析为资产。指定设备未被真实可下发目录返回时停止，不推断未纳管或权限不足，不换设备。具体 configKind、operation、配置键和 `payload` 按实时合同确定。不熟悉配置 `payload` 时，填写前先读取该设备及配置类型对应的真实配置与 `input-fields` 合同，已有有效结果直接复用；依当前返回的 `fieldName`、类型、必填约束和枚举值填写，不自造或翻译字段名，不猜测枚举值。合同中的可选字段不得升级为必填，不猜厂商参数；具体字段表只以真实合同为事实源，不在本 Skill 复制维护。确定性发现、字段衔接与校验交给组合，不由模型手工重跑原始接口链。
3. **按本轮授权选择 stop。** `preview`：取得真实渲染与检查结果后停止，不保存任务；`draft`：在有效预览后保存原 SOC 草稿并按返回任务号回读，不提交或执行；`apply`：用户明确要求真实下发时，按原任务及 SOC 实际前置条件推进预检、提交、审批或执行，并核对原结果。参数完整且授权明确时直接办理，不机械增加二次确认；不得将只预览、只草稿的请求提升为 apply。只传实际目录支持的参数和停止位置。
4. **原号恢复，不重建。** 组合已负责有界读重试；收到 `preview blocked` 等终止结果且没有新事实时，报告停点后停止，不由模型修改无关 `changeReason` 或重跑同一链。已有可用 `taskId` 时，用组合当前恢复合同续办该原任务，不重新预览建任务；用户仅查状态、跟踪或试运行结果时，使用 `policy-response` 原始查询资源读取同一任务，不续办写入。平台 `run_id` 仅用于标识和查询同次组合运行，不得充当 SOC `taskId` 或审批 `workflow instanceId`，也不能由其推导这些标识。只有有真实契约依据的参数校验失败且已确认本次未写入时，才修正参数并在原授权内重试；HTTP 500 不等于参数校验，不据此改参数重跑。保存或下发超时、断线、结果未知时先查原 taskId；无号时仅按已知关联条件有限核对原任务目录，有充分证据才认领。仅按任务名查到空列表不足以证明没有写入，不无目标反复查任务或以查询代替修正参数。无法确认结果时报告未知，不自动重新创建或重放写步骤。
5. **保持边界与失败证据。** 批量保留合格子项、排除原因和完整覆盖范围，按上游 changes 合同保存同一任务；组合未支持批量时说明能力缺口，不拆成模型逐项执行的固定链。审批只在真实 workflow/task ID 和明确授权下办理。`acl-hit` 只用于现有规则命中调查，`entity-data` 只在当前配置确实依赖实体数据时读取，均非准备必经步骤。拒绝、预检失败、权限不足或依赖失败不得以改换设备、放宽参数或越过 stop 排障。500 文案不证明具体根因，也不能据此排除参数、权限等可能性或断言无业务写入。

简洁交付用户意图、真实预览、当前阶段、原任务号及证据缺口。严格区分已预览、已保存、已受理、审批中、执行中、阻塞、失败、未知和真实设备效果；保存、HTTP 成功或接口受理不证明规则已生效。有证据未执行时只说明“本次未下发”，写入结果未知则保持未知；未取得设备或规则查询证据时明确“设备当前状态未验证”，不因本次未执行就断言设备当前无规则或未生效。取消未保存方案只结束交互；已保存任务的变更或回滚仅按用户授权和 SOC 实际合同办理，不自动补偿。
