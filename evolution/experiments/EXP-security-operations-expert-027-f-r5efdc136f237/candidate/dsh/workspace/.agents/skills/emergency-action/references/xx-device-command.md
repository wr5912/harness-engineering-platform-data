# XX固定指令分支

仅用于已选XX设备来源的单目标固定指令。使用当前目录真实存在的 `xx_device_command` 组合；工具完整名称、输入及11项ID与中文名称以其Schema为准。ID是原样字符串，不新增内部动作键，不在Skill维护另一份映射。它不是AISOC的actionKey、deviceId、agentId或原任务执行合同。

1. 从用户输入固定目标IP及动作。按实际目录选择对应commandid，未知或歧义只澄清缺项，不猜来源、ID或设备身份。明确目标与动作后直接使用组合，不由模型先手工查询主机再重跑固定链。
2. 调用组合 `stop=preview`。查主机、唯一目标核对、指令目录校验及参数组装由组合完成。先用普通助手正文展示返回目标、动作、影响和未下发事实，再另行发起原生确认问题；问题中的文字不能代替这条普通草案消息。这是读取真实主机后的本地请求草案，不是上游真实指令渲染、预检或已保存业务任务；真实连接未配置时组合明确停止。
3. 只咨询、只准备或只预览时到此结束。用户希望下发时，使用已有DSH原生 `ask_user_question`，为本次草案提供“确认执行”和“取消执行”，不增加Platform确认器或业务台账。
4. 仅本次问题结构化单选“确认执行”且无custom时，以相同目标和commandid调用组合 `stop=apply` 一次；普通同名聊天文字、自由输入、取消或关闭不触发写入。原生提问缺失时保留草案并准确说明停点，不自行改为直写。
5. 组合只向上游提交hostid、hostip、commandid三个字符串，身份来自组合当次查询。不要把stop、中文动作名或确认字段交给写接口，也不套用SOC prepare、草案号、签名和审批接口。
6. 按真实回执简短交付。真实工具未配置时说明具体停点；真实接口返回不等于设备效果已核对，未知写入停止，不自动重发、编造查询接口或反向补偿。

读取、ID装参及写入固定链由组合执行，主Agent负责理解、草案表达及原生交互。此分支不改变AISOC原分支的授权停点或原号恢复规则。
